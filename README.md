# Library Management System

## Project Description

This project is a Library Management System developed using Java. It allows users to manage book and member information through a menu-driven program.

The system supports adding books, registering members, displaying book and member records, borrowing books, and returning books.

## Classes

- **Book.java** — Stores book information and manages book attributes.
- **Member.java** — Stores library member information.
- **Library.java** — Manages books, members, borrowing, and returning operations.
- **Main.java** — Displays the menu and handles user input.

## Object-Oriented Programming Concepts

This project demonstrates classes and objects, encapsulation, constructors, getter and setter methods, selection statements, and looping structures.

## Requirements

- Java Development Kit (JDK)
- A Java editor or terminal

## How to Run

1. Download or clone this repository.
2. Open the project folder in a terminal.
3. Compile the Java files using:

   `javac *.java`

4. Run the program using:

   `java Main`
